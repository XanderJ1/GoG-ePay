# PENITENT demo — proposed scope for client agreement

This document is prepared for review; it has not been sent or accepted.

## Deliverable
A hosted clothing demo built with SvelteKit/TypeScript, ASP.NET Core .NET 10, EF Core, and PostgreSQL. Includes 12 sample products across T-shirts, hoodies, and trousers; campaign/story pages; filters; product variants; inventory; server-calculated persistent bags; browser-local saved pieces; a guest checkout preview; and protected product/inventory management.

Checkout validates sample contact and address details and shows a preview. No payment is collected, no real order is created, and no inventory is deducted.

## Boundaries
One consolidated feedback round within the agreed week. Payments, customer accounts, real orders, shipping, returns processing, coupons, uploads, and campaign management are reserved for a separate paid scope.

## Items to agree before starting the client delivery clock
- Start date: to be agreed.
- Completion date: Day 7 after the agreed start; confirm the calendar date in writing.
- Client approval of temporary copy and illustrative licensed clothing imagery.
- Hosting costs and who pays them; no paid infrastructure has been provisioned.
- Demo access duration and removal date: to be agreed.
- Source-code ownership, repository access, and handover terms: to be agreed.
- A subsequent full website engagement is separate from this unpaid evaluation.

## Acceptance
The client can browse clothing, select a variant, edit a persistent bag, validate checkout, and preview accurate server totals. A private admin can change products and inventory and observe those changes in the storefront. Test evidence and setup/API documentation accompany the demo.
